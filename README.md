# Deep · Disparo Inteligente de WhatsApp para o FutebolCard

Landing page (proposta comercial) da Deep para o serviço de disparo de WhatsApp
segmentado pela API Oficial da Meta, voltada à base de torcedores do FutebolCard.

## Conteúdo
- `index.html` — site completo, single-page, sem dependências de build (HTML + CSS + JS inline).

## Como publicar

### Vercel (recomendado)
1. Acesse https://vercel.com/new
2. Importe este repositório do GitHub **ou** arraste a pasta do projeto.
3. Framework Preset: **Other** (site estático). Não precisa de build.
4. Deploy.

### Rodar localmente
Basta abrir `index.html` no navegador, ou:
```bash
npx serve .
```
